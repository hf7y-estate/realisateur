Machine-readable: status.json. Published by realisateur/bin/estate-watch.sh from bin/estate-status-collect.py, both running on dexter, where docker and /srv are. Services are the long-lived containers, one per /srv/<name>/compose.yaml; a service marked on demand carries .no-autostart and its resting state is stopped, so stopped is not a finding there. Passes are the one-shot --rm containers the nightly dispatcher spawns, one per repo; a pass is graded on what it left — a REPORT.md and, usually, a PR — never on its exit code alone, because a pass that reads the queue and honestly writes “nothing finishable from here” also exits 0. The PR column is read off the report the pass wrote, never off the PR's author: the container pushes with the estate's own token, so every PR it opens is authored hf7y. This page is not a census of the host — containers no compose file declares are listed but not graded. When dexter is down nothing republishes, so read valid until before you read the verdict.
